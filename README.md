# Happy Ghast Speed Boost

This mod adds the ability to speed up your Happy Ghast by feeding it kibble. The kibble is crafted from rotten flesh, sugar, and a snowball.

![Ghast Kibble Recipe](https://github.com/ckoval7/happyghastboost/blob/b722590c7c778dc109b34d0f4ae68e204ae9675b/Screen%20Shots/recipe.png)

When you are riding a ghast, you will be presented with a Ghast Stamina Bar in your display.

![Ghast Stamina Bar](https://github.com/ckoval7/happyghastboost/blob/b722590c7c778dc109b34d0f4ae68e204ae9675b/Screen%20Shots/stamina_bar.png)


## Installation

1. Download the latest release
2. Place the `.jar` file in your server's `mods` folder
3. Start your server - configuration files will be created automatically

This mod must be installed on both server and client.
