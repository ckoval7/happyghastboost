# Happy Ghast Speed Boost
A Minecraft mod that adds a stamina-based speed system for Happy Ghasts, making them faster and more useful as flying mounts!

## Features

### 🍖 Ghast Kibble
- **Craft Ghast Kibble** to feed and restore stamina to Happy Ghasts
- **Recipe**: Surround a snowball with sugar and rotten flesh in a crafting table
    

- **Yields**: 4 Ghast Kibble per craft
- Hold kibble in your hand to attract nearby Happy Ghasts (they'll follow you!)

### ⚡ Stamina System
- Higher stamina = faster flying speed
- Stamina depletes while riding
- Feed kibble to restore stamina

### 🚀 Speed Boost
- Speed stays high until stamina gets low, then drops sharply

### 📊 Stamina Bar
- Displays on-screen when riding a Happy Ghast
- Shows stamina as heart-like icons (similar to health)
- Located on the right side of the screen, mirroring the ghast's health bar

## Installation

### Requirements
- Minecraft **1.21.8+**
- NeoForge **21.8.47+**

### Steps
1. Download the mod `.jar` file
2. Place it in your `.minecraft/mods` folder (or server's `mods` folder)
3. Launch Minecraft with NeoForge

## Usage

### For Players

**Getting Started:**
1. Craft Ghast Kibble using the recipe above
2. Find your Happy Ghast
3. Hold kibble to attract the ghast (they'll float toward you)
5. Feed kibble to build stamina

### For Server Operators

**Configuration File**: `config/happyghastboost-common.toml`

This file is automatically generated on first run. You can adjust all values to suit your server's needs.
